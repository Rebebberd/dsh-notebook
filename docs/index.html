一个知识箱，四种学习方式

资料、问答、笔记、做题彼此连通，笔记本身也会参与检索。

📚

资料

一次导入多个文件或整个文件夹，支持 Markdown、纯文本与 PDF；右侧可随时查看原文。

💬

问答

回答只依据箱内资料，并标注出处；选中任意文字即可「就这段提问」。

📝

笔记

自动分区的知识点笔记，可编辑、打标签、按需合并导出为 Markdown。

🎯

做题

按题型与难度出题，错题自动进入错题本，随时重做。

本地、安静、可掌控

所有资料、笔记、问答记录都存放在你自己的机器上，不上传任何服务器。

数据在本地

内容保存在 DSH 的存储目录，随你的备份策略走。

字体可换

正文与代码字体分别设置，可导入自己的字体文件。

批量整理

资料、笔记、聊天都支持多选批量删除，笔记还能批量导出。

# NoteBook 学习区

DeepSeek Harness 的学习区插件：把「资料 → 问答 → 做题 → 错题 → 笔记 → 导出」放在一个面板里。

- **黑箱资料**：导入文件 / 文件夹 / PDF / 粘贴文本；问答只依据箱内资料（含你自己写的笔记），不联网。
- **模型可选**：四个区都能切换模型——问答、出题、判题、提示、笔记总结与资料画像都跟随所选模型；DSH 里接入的第三方 API 会按服务分组出现在列表里，可同时使用官方与第三方模型。
- **问答**：流式输出、Markdown、KaTeX 公式（可复制给 Obsidian）、代码高亮；聊天区附件、历史定位、选区「待发送」、侧栏边看边问。
- **检索**：回答只带「资料画像 + 命中片段」而非整箱全文；命中为空时自动扩大到整箱并在回答上标注「本次按整箱范围回答」；检索片段数可在设置里调（3 / 5 / 8）。
- **资料画像**：导入时生成一份约 200 字的概括（`materials[].summary`），旧资料在打开学习区时惰性补齐；资料行显示「已索引 / 待索引」，右键可「重建索引」。
- **做题**：从箱内资料出题（选择 / 开放·代码 / 混合），难度可选（基础 / 中等 / 进阶 / 不限），范围可选全部资料或指定一份，可选联网参考题型；逐题生成、逐题保存，可随时「继续出题」；作答前不展示答案，答错才给「参考答案与评分要点」与改法，答对只补一句要点。
- **判分**：选择题先在本地定对错，再调用一轮模型说明「你选的这个选项为什么不成立」，并给一句下次做题能用上的提示；开放题只上传题目 + 参考答案 + 评分要点 + 学生答案，不附带资料摘录。解析始终围绕学生这一次的作答来写，答案有问题逐条指出错在哪里、怎么改；答错自动进错题本，支持重做，答对自动标记已复习。
- **题目导入笔记**：做题区可多选勾选已出的题目，导入为「典型题目/错题」分区的新笔记（含选项、答案、评分要点与解析）。
- **笔记**：可编辑、分区、标签；`辅助总结`（把笔记整理成结构化摘要）与`今日总结`（汇总当天问答）；笔记参与检索。
- **导出**：Markdown（知识点笔记 / 练习题 / 错题本 / 今日问答 / 知识扩展 / 全部），带 `[[资料名]]` 跳转与行内补偿讲解，可直接放进 Obsidian。
- **设置**：默认笔记分区、默认题型、默认难度、出题是否默认联网。
- **主对话集成**：宿主聊天每条回答后多一个「存到学习区」图标；另注册工具 `notebook_save_note`，普通对话里说「记到学习区」即可保存。

## 安装（本地）

在 Harness 里让 Agent 执行：

```
plugin_manager install_bundle  target = <本目录的绝对路径>
```

或者把整个目录放到任意位置，用同样的绝对路径安装。安装后侧边栏出现「学习区」图标。

也可以使用打包好的 tarball（`dsh-notebook-0.1.0.tgz`）作为 target。

## 数据位置

所有数据都在本机，没有服务端：

```
$DSH_HOME/notebook/
  boxes.json            # 学习区索引
  boxes/<id>.json       # 每个学习区的完整记录（资料原文、问答、笔记、错题、练习题）
  materials/saves/<学习区名称>/<资料名称>.md  # 聊天新增、粘贴资料及旧资料副本
```

`$DSH_HOME` 默认是 `~/.dsh`。备份/迁移直接拷这个目录即可。

Windows 下导入文件/文件夹使用宿主原生选择器，记录文件的真实路径，文件保留在导入前的原位置。「打开文件位置」定位原文件；移除资料只移除索引，不删除原文件。聊天中新建或粘贴的资料存入上面的 `materials/saves`。

资料目录与文件使用可读名称，重名加数字后缀；重命名学习区后会迁移其生成的 Markdown。资料目录中的 `.notebook-owner.json` 仅用于避免同名学习区互相覆盖。旧哈希路径会迁移至可读路径。

旧版本的 `storages/notebook` 数据会兼容读取并复制到新目录，保留旧目录。旧资料如果没有原始路径，只能继续使用保存的副本；旧 PDF 若没有二进制，只能补存提取后的 `.txt`。

问答区支持同一学习区内新建、切换聊天。各聊天共享资料和笔记，问答历史与模型对话上下文分别保存；旧问答归入「原有聊天」。

聊天选择器和「新聊天」位于输入区，长对话滚动时仍然可见。右键点击当前聊天或下拉列表中的聊天，可重命名或删除；删除聊天会移除该聊天的问答，不影响共享资料和笔记。

聊天首次问答后自动概括主题命名；手动修改过的名称会保留。复制回答、存为笔记、记为错题会显示短暂的顶部提示，依据和扩展不显示此提示。

设置中可选择哪些笔记作为参考资料：今日知识点笔记、今日总结、其他笔记，可多选或全部取消；导入资料不受此开关影响。资料删除需要确认，原文件保留，插件保存的副本会移除。

出题逐题生成以隔离输出 token 预算，使用较低推理开销；每出一题立即保存，中途关闭面板后可「继续出题」续上，已出题目不丢失。截断或 JSON 不完整时重试当前题目，不减少用户要求的题数。未指定主题时直接从可用资料选取内容；选了指定资料时只取这一份的分块。

三条链路的内容由一处控制：问答取「画像 + 命中片段」，出题取指定范围的摘录，判题不读资料（只对照参考答案与评分要点）。要在以后调整策略，只改这一处。

选中问答或资料中的文字，可「补充到笔记」。默认追加到最新创建的笔记，也可临时选择其他笔记，或在设置中指定默认笔记。还没有笔记时会创建一份摘录笔记。

选中文字后也可以点「待发送」：选中内容以黑色小框单独显示在聊天框上方，可在下方补充问题后一起发送，发送后自动清除。

资料侧栏支持实时拖动宽度，以动画帧合并更新并缓存公式渲染；聊天定位条采用均匀间距，点击平滑定位，手动滚动可中断跳转。

笔记的「导出」保存当前选定笔记（编辑后请先保存）；「批量导出」打开独立对话框，可选择知识点笔记、练习题（含答案与解析）、错题本、今日问答、知识扩展或「合并导出」。

## 依赖

- 运行期只需要 Harness 自带的 React 与宿主服务（`connection` / `webServer` / `llm` / `agentDefaultModel`）。
- 内置 KaTeX（MIT）用于公式排版，文件在 `vendor/katex/`，由插件自己的路由本地提供，不联网。
- 联网搜索是可选能力：只有勾选「联网参考」且 profile 启用了 web provider 时才会调用。

## 隐私

- 资料、问答、笔记只写本地磁盘。
- 「联网参考」开启时，题目文本会发给当前配置的 web provider；其余情况不外发，除了正常调用你自己配置的模型。
